# Generated market fixture

`btc-usd-1h.json` is a synthetic, deterministic OHLCV dataset created for Trading Mentor AI. It does not reproduce exchange data and has no external licensing dependency. Prices are illustrative and must not be treated as real market history.

Sprint 03 creates `sessions.sqlite3` in this directory when the API starts. It is local runtime data, is excluded from Git, and contains versioned simulator checkpoints and their idempotency ledger. To start with an empty local history, stop the API and remove only that database file.
