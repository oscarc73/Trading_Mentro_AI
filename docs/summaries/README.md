# Project Action Summaries

This directory is the chronological record of completed actions in Trading Mentor AI. It complements `docs/STATUS.md`, which describes the current state, and `docs/DECISIONS.md`, which records material decisions.

## Naming convention

Use an ISO date followed by a concise uppercase action name:

```text
YYYY-MM-DD_ACTION_NAME.md
```

When several actions share a date, add a two-digit sequence after the date:

```text
YYYY-MM-DD_02_ACTION_NAME.md
```

## Required contents

Every summary must record:

1. Outcome.
2. Scope completed.
3. Files or areas affected.
4. Decisions and assumptions.
5. Commands and verification results.
6. Manual verification.
7. Limitations or follow-up work.
8. Documentation updated.

Summaries are historical records. Do not silently rewrite an older summary to describe later repository behavior; add a new dated summary instead.
